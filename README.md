🏋️ FitLog — Workout Library

FitLog is a modern and responsive workout library designed to help users explore exercises, view detailed workout information, and create a personalized workout plan. The project features a clean dark-themed interface and provides a smooth experience across mobile, tablet, and desktop devices.

🚀 Technologies Used

Next.js — React framework for building the application

React — Component-based UI development

Tailwind CSS — Responsive styling and layout

DaisyUI — UI components and loading animations

JavaScript (JSX) — Application logic and components

REST API — Fetching workout and exercise data

✨ Key Features

1. 🏋️ Workout Library

Browse a collection of exercises and workouts fetched dynamically from the FitLog API.

2. 🔎 Workout Details

View detailed information about individual exercises through dedicated workout detail pages.

3. 📋 Personalized My Plan

Save selected workouts and manage a personalized workout plan for future training sessions.

4. 📱 Fully Responsive Design

The application is optimized for mobile, tablet, and desktop screens for a consistent experience across devices.

5. ⚡ Loading & User Feedback

Includes loading animations while data is being fetched and toast notifications to provide clear feedback when users interact with workout features.

🎨 Design

FitLog uses a dark, modern fitness-inspired interface designed to provide a focused and comfortable workout browsing experience.


📌 Project Highlights

Dark-themed modern UI

Responsive design

Dynamic API-based workout data

Personalized workout planning

Smooth loading and user feedback experience
